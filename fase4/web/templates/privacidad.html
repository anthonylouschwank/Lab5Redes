Aviso de privacidad

Este portal es un proyecto académico del curso CC3067 Redes (UVG). El Hospital Privado Castillejos es una organización ficticia.

  • Datos que se piden: nombre, especialidad, fecha, hora y un motivo breve. Use solo datos ficticios.
  • Datos que NO se piden: expedientes, diagnósticos, documentos de identidad, teléfonos ni correos.
  • Finalidad: demostrar la gestión de citas en un servidor web público con HTTPS.
  • Acceso: la consulta solo muestra las iniciales del paciente y requiere el código de la cita.
  • Conservación: los datos se eliminan al finalizar el proyecto.
  • Seguridad: la comunicación viaja cifrada con TLS (Let's Encrypt) y el servidor está en una DMZ aislada de la red interna.
